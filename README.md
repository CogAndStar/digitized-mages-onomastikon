# digitized-mages-onomastikon
A couple of name generators for a couple of CogAndStar's settings, written in Python.

At present, they both just run in command line.

The generators are:

  wizard-name-generator.py, a generator for mainstream Union wizards.

  pukwudgie-namer.py, a generator for pukwudgies.

  ecumenical-space-names.py, a generator for planets and people in Ecumenical Space.

  ygg-name-generator.py, a generator for ygg names.

  stars-incline-names.py, a generator for inhabitants of the Natural Order and dragons.
